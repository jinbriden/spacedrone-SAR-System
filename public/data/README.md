# Natural Earth 国界数据

`ne_110m_admin_0_countries.geojson` 来自 Natural Earth Vector 的 1:110m Admin 0 Countries 数据，用于离线国界显示。

- 上游项目：https://www.naturalearthdata.com/downloads/110m-cultural-vectors/110m-admin-0-countries/
- GeoJSON 来源：https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson
- 获取日期：2026-07-16
- 许可：Natural Earth 数据属于公共领域。

本项目未改变几何，仅在 Cesium 中以透明填充和矢量描边显示。
