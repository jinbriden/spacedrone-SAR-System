# 星载天线对地扫描三维仿真平台

这是技术文档中里程碑 1～6、第二阶段扩展及第三阶段 SAR 链路的逐步实现：在浏览器中显示 WGS84 三维地球、多颗独立轨道卫星、LVLH/本体姿态、带相位中心偏移的固定安装天线、随时间变化的扫描规律、DEM 地形与遮挡、目标重访统计，以及由真实地表射线求交得到的瞬时和累计覆盖区；同时支持版本化场景文件、目标导入、轨道与覆盖数据导出和 Web Worker 后台采样。

## 安装与启动

要求 Node.js 20 或更高版本。

```powershell
npm install
npm run dev
```

浏览器打开 Vite 输出的本地地址。生产构建与测试命令：

```powershell
npm test
npm run build
npm run preview
```

## 操作

- 轨道输入可选“简化圆轨道”“开普勒六根数”或“TLE / SGP4”。六根数模式支持半长轴、偏心率、倾角、RAAN、近地点幅角以及真/平近点角；近地点落入地球时禁止应用并给出修正建议。
- TLE 可粘贴或导入标准两行/三行 `.tle`、`.txt` 文件；界面校验行号、69 字符长度、逐行校验和及卫星编号一致性，显示 NORAD 编号、TLE 历元、平均周期和 SGP4/SDP4 分支，并允许将仿真历元同步到 TLE 历元。
- “多星编队”可从主星克隆最多 31 颗伴飞星，分别配置启用状态、名称、颜色、轨道类型对应的完整轨道参数和独立历元，也可一键均匀分配同轨相位或重新同步主星姿态/天线。伴飞星使用同一主星仿真 UTC，因此不同轨道历元会先换算为各自传播时间。
- 圆/开普勒输入的传播模型可选“二体开普勒”或“一阶 J2 平均根数”。J2 模式产生 RAAN、近地点幅角和平均近点角的长期漂移，右侧显示 RAAN 漂移率；它不包含短周期项、阻力或高阶重力场。
- 可开启或关闭物理地球自转。关闭后 ECI→ECEF 使用固定历元旋转，不扣除地球角速度项。
- 地球使用 CesiumJS 随包提供的离线 Natural Earth II 贴图，并叠加项目内置的 Natural Earth 1:110m 矢量国界；贴图、经纬网和国界可分别关闭，无需地图服务令牌或运行时网络请求。
- 鼠标拖动地球可旋转视角，滚轮可缩放；单击地球会在右侧显示拾取位置的经纬高，双击会定位并拉近到该位置。
- 底部可播放、暂停、前后单步、重置，并选择 0.1× 到 1000× 的仿真倍率；支持拖动时间轴以及输入起始、当前和结束仿真秒数。
- 蓝色曲线是当前历元下的三维轨道线，黄色曲线是考虑地球自转的一周地面航迹，红点是当前星下点。
- 在“姿态与天线”中可实时修改本体 roll、pitch、yaw 和天线固定安装角。虚线短轴表示 LVLH，实线短轴表示本体坐标系；黄色线表示天线波束中心方向。
- 姿态来源可选固定 RPY 或外部姿态 CSV。外部序列表头为 `timeSeconds,rollDeg,pitchDeg,yawDeg`，时间非负且严格递增，各轴跨 ±180° 时沿最短角路径插值，范围外保持端点，最多 10000 点。
- 可配置最大滚转、俯仰、偏航角以及最大角速度和角加速度。固定姿态和外部序列共享同一校验；序列角速度使用最短角三轴合成值，角加速度由相邻线性段中点速度差计算，首版仅校验而不模拟控制器动力学。
- 可选择圆锥或矩形角域波束，实时修改扫描方位角、扫描俯仰角、全波束宽度和 64～128 个边界采样点。
- 扫描规律可选固定、正弦和线性往返；可设置扫描轴、幅度、周期和初始相位，右侧实时显示叠加后的有效方位角与俯仰角。
- 第二阶段自定义扫描时间表支持 CSV 导入，表头固定为 `timeSeconds,azimuthDeg,elevationDeg`。时间必须非负且严格递增，双轴角度按时间线性插值，早于/晚于表格范围时保持首/末端值，最多 10000 点。
- 任务扫描模式支持 Stripmap 固定条带、Spotlight 点目标持续跟踪、ScanSAR 多子测绘带 burst 轮换，以及 TOPS 方位单程扫掠；所有任务指向都经过同一机械扫描角限幅和 WGS84 覆盖链。
- 二维增益方向图支持 CSV 长表和 JSON 规则网格导入，以双线性插值提取相对峰值 3 dB、10 dB 或自定义门限的主瓣边界；方向图角域不足时会明确提示覆盖区被截断。
- 天线参数还包括本体坐标系三维安装位置、最大扫描角、波束颜色和透明度。射线从真实天线相位中心出发；超限扫描请求按最大角饱和并保留请求角供诊断。
- “多波束与阵列馈源”在主馈源之外最多配置 31 个附加馈源。每个馈源保存启用状态、天线坐标系三维相位中心、双轴指向偏置、波束宽度倍率、相对功率和显示颜色；它们共享主天线任务扫描规律与方向图，但分别执行扫描限幅和地表求交。
- 点/区域目标以全部启用波束的并集判断命中；主星和伴飞星均显示附加波束轴与瞬时覆盖。固定时间累计扫描带、覆盖几何并集、Worker 采样和 GeoJSON 导出同样包含全部波束。
- 青色地表多边形来自每条波束边界射线与当前地表的真实交点；未启用 DEM 时使用 WGS84 椭球，启用后使用规则网格高程面并可在网格外回退到 WGS84。右侧显示中心经纬高、DEM 命中/回退数、斜距、入射角、沿轨/横轨尺寸和局部投影面积。
- “数字高程与地形遮挡”支持 CSV 长表或 JSON 规则网格导入，限制为 250000 个网格点；三维视图显示半透明高程三角网。目标视线按可配置距离间隔采样，遮挡状态同时作用于实时命中、重访分析、任务规划和后台导出。
- 当中心或部分边界射线不命中地球时，界面会隐藏覆盖多边形并说明命中数量和失败原因。
- 可按输入经纬高或地球拾取点添加点目标、圆形区域、局部东西/南北矩形区域和任意多边形区域。区域命中由区域边界与瞬时波束覆盖区的真实相交决定；状态区继续显示地平线可见性、斜距、入射角、天线角偏差和照射统计。
- “可见性与重访分析”在独立 Web Worker 中对主星和全部启用伴飞星生成逐星窗口，并以“任一卫星命中”生成星座联合地平线可见/真实波束覆盖窗口；统计访问次数、总持续时间、覆盖率、重访间隔及包含分析边界的最大未覆盖空档。粗采样用于发现状态变化，进入/离开边界再二分细化到配置容差；短于粗步长且未命中采样时刻的窗口可能漏检，窄波束应减小步长。
- “目标区域任务规划”为每个启用目标配置优先级、所需观测时长、最早开始、最晚结束、最小连续段和是否允许拆分。Worker 对每个“卫星 × 任务”临时采用 Spotlight 指向，经过最大扫描角限幅和真实 WGS84 覆盖相交得到机会窗口，再按高优先级、早截止顺序分配；同一卫星不重叠，同一任务不由多星重复同时累计。
- “SAR 快慢时间与多普勒”保存分析目标、孔径中心时刻、载频、线性调频带宽、脉宽、PRF、复基带采样率、孔径时间和快时间余量。后台 Worker 按 PRF 对主星真实 ECEF 位置/速度采样，输出单基地双程时延、斜距速度、多普勒历程、最近斜距、中心/带宽估计和快时间窗，并可导出 CSV。
- SAR 面板同时给出波长、理论距离分辨率、最大无模糊距离、最大无模糊径向速度、占空比、时宽带宽积及快/慢时间采样点数；斜距与多普勒曲线使用降采样绘制，导出数据保留全部 PRF 采样点。
- “生成 LFM 复回波”从完整孔径中截取以最近斜距为中心的连续 PRF 脉冲，按单点目标模型生成脉冲主序、快时间次序的 I/Q 矩阵。模型包含双程载波相位、线性调频相位、RCS 与 R⁻² 归一化幅度及可复现复高斯噪声。
- 距离模糊按双程时延对 PRI 取模并报告模糊阶数与表观距离；方位模糊把多普勒折叠到 [-PRF/2, PRF/2)，报告阶数和估计谱副本数。回波幅度以 60 dB 动态范围显示，并可导出自描述的 `SPDRIQ1` 交织 Float32 二进制文件。
- 多通道模式采用中心相位中心发射、2～32 个沿轨分置相位中心接收；每个通道分别计算 `R_tx + R_rx` 路径、时延、载波相位和 LFM 回波，而不是复制单通道数据。
- DBF 根据通道位置、平台速度和指向多普勒生成归一化复权并合成完整回波。方位频谱重构在每个基带频点建立通道—模糊谱复矩阵，分离与通道数相同的谱副本；奇异矩阵会中止并提示调整间距、PRF 或阶数。
- DBF 结果包含合成回波幅度图、宽方位频谱、复权和消元主元诊断，可导出频谱 CSV，以及自描述的 `SPDRDB1` 多通道原始/DBF I/Q 二进制。
- “运行参考 SAR 聚焦”通过算法注册表调用 `reference-range-backprojection`：先对每个脉冲执行 FFT 距离匹配滤波，再依据真实轨道斜距历程作最近邻距离徙动校正、双程载波相位补偿和慢时间相干积累。界面显示归一化 dB 图、峰值位置、PSLR 与 3 dB 宽度，并可导出 `SPDRIMG1` Float32 图像。
- “累计扫描带”按独立的仿真时间间隔保留历史覆盖区；默认每 10 仿真秒采样一次、最多保留 240 个，采样数量不依赖渲染帧率。
- 累计覆盖可选择逐帧“轨迹带”或真实几何并集。并集会合并重叠覆盖、保留独立区域和孔洞，并在 ±180° 日界线处分割后显示；原始历史帧继续保存在场景中以便加载时重算。
- 顶部“保存场景”导出带 `schemaVersion: 1` 的 JSON；“加载场景”恢复参数、目标、当前时间、目标照射统计和累计扫描带。未知版本或字段缺失时会显示具体迁移/修正提示。
- “导入目标”接受 CSV 或 GeoJSON Point/Polygon。CSV 用 `targetType` 区分 point/circle/rectangle/polygon，并分别使用 `radiusM`、`widthM,heightM` 或 JSON `vertices` 字段；旧点目标表头保持兼容。
- “导出 CSV”与“导出 GeoJSON”在 Web Worker 中按一周轨道 361 个固定时间点计算。CSV 包含卫星 ECI/ECEF 位置、ECI 速度、姿态四元数、波束中心、斜距、入射角和覆盖面积；GeoJSON 包含地面航迹、波束中心轨迹以及带斜距/入射角属性的每个闭合覆盖多边形。
- “示例场景”可直接载入通用扫描、J2、TLE/SGP4、外部姿态以及四种 SAR 任务模式。可下载文件示例位于 `public/examples/`。
- “显示图层”可分别关闭地球贴图、经纬网、国界、地心/地轴/赤道面、轨道、地面航迹、局部轴、波束、瞬时覆盖区、目标和累计扫描带；昼夜光照是纯显示开关，不改变轨道或覆盖计算。顶部相机可选自由、跟随卫星、跟随星下点或跟随波束中心，点击卫星也会进入跟随模式。
- 主星可从 URL 或本地文件加载 glTF/GLB 模型；URI 为空、清除模型或未配置模型时使用机身、双侧太阳翼和天线图标组成的简化模型。0.25×～4× 缩放只改变模型视觉尺寸，不改变物理几何与波束计算。
- 悬停卫星会显示 UTC、经纬高和速度，悬停覆盖区会显示中心、面积和入射角；“截图”下载当前三维画布 PNG，“帮助”给出交互、导入格式和 WebGL 排错说明。
- 浏览器不支持 WebGL、Cesium 初始化失败或 WebGL 上下文丢失时，视图区会显示原因和可操作的修复建议；未捕获的 React 错误由应用级错误边界接管。

## 数学模型与坐标系

- 地球采用 WGS84 椭球，长半轴 `6378137 m`，扁率 `1 / 298.257223563`。
- 内部长度、速度、时间和角度统一使用 `m`、`m/s`、`s` 和 `rad`；界面使用 `km`、`km/s` 和 `deg`。
- 圆轨道半径为 WGS84 长半轴加轨道高度，速度由 `sqrt(mu / r)` 计算。一般椭圆轨道使用半长轴、偏心率和轨道角元素；通过 Newton 迭代求解 `M = E - e*sin(E)`，再在近焦点坐标系生成位置/速度并按 `Rz(RAAN) Rx(i) Rz(ω)` 转到 ECI。两种模式的周期均由 `2*pi*sqrt(a^3/mu)` 决定，速度不是独立输入。
- ECI 采用地心惯性坐标；轨道面通过 `Rz(RAAN) Rx(inclination)` 转换到 ECI。
- ECI 到 ECEF 使用 UTC 时刻的格林尼治平恒星时，并在 ECEF 速度中扣除地球自转项。
- 关闭地球自转时固定使用历元的格林尼治角，速度只做坐标旋转，不减去 `ω×r`。
- J2 平均根数模型采用 `p=a(1-e²)`，并使用一阶世俗变化率：`Ωdot=-3/2 J2 n (Re/p)² cos(i)`、`ωdot=3/4 J2 n (Re/p)²(5cos²(i)-1)`，平均近点角同时加入对应的一阶长期修正。ECI 速度包含轨道面和近地点方向旋转产生的导数项。
- TLE 模式使用 `satellite.js` 的 SGP4/SDP4 实现并输出 TEME 位置（km）和速度（km/s），进入核心层时统一转换为米制。当前显示链将 TEME 作为 ECI 兼容惯性状态，并按 UTC 的 GMST 旋转到 ECEF。
- ECEF 与经纬高之间使用 WGS84 椭球转换。地面航迹对每个采样时刻分别执行 ECI 到 ECEF 转换，因此不会与惯性轨道投影重合。
- 仿真时钟以测得的真实时间差乘播放倍率推进，不以渲染帧数作为时间步长；单步操作固定推进 1 仿真秒。
- LVLH 定义固定为：`+Xs` 沿速度正交化方向，`+Zs` 指向地心，`+Ys = +Zs × +Xs`。代码验证三个轴正交归一且 `Xs × Ys = Zs`。
- 本体相对 LVLH 采用 `R_body<-LVLH = Rz(yaw) Ry(pitch) Rx(roll)`；天线固定安装矩阵使用相同欧拉角顺序。零姿态、零安装角时，天线 `+Za` 与 LVLH 天底 `+Zs` 重合。
- 外部姿态序列仍采用同一 RPY 定义和旋转顺序。每一轴按 `wrapToPi(next-current)` 得到最短角差后线性插值；导出的姿态四元数由插值后的有效 RPY 计算并保持单位归一。
- 天线角域约定：正方位扫描朝 `+Xa`，正俯仰扫描朝 `+Ya`，零扫描沿 `+Za`。矩形波束沿角域矩形的四条边按顺序采样，圆锥波束按半锥角等相位采样。
- 天线安装位置用本体坐标系米制偏移表示，经本体到 ECEF 矩阵转换后作为所有波束射线的统一原点。
- 正弦扫描为 `amplitude * sin(2*pi*t/period + phase)`；线性往返扫描使用等速三角波，取值范围均为 `[-amplitude, +amplitude]`。扫描偏角叠加到手动扫描方位或俯仰角。
- 射线方向先归一化，再代入 WGS84 椭球二次方程；判别式小于零或正根不存在时判定无交点，否则取最小正根。
- DEM 使用严格递增的规则经纬轴和双线性高程插值；以 WGS84 交点为初始包络，对射线上“椭球高－DEM 高程”做二分求根。目标地形遮挡沿卫星至目标的 ECEF 直线分段采样。
- 只有全部边界射线命中且不少于 3 个交点时才生成闭合覆盖区。部分命中不会被补线或投影成虚假多边形。
- 访问窗口以布尔状态变化定义。相邻波束覆盖窗口的 `next.start - previous.end` 为重访间隔；最大未覆盖空档还计入分析起点至首个窗口、末个窗口至分析终点。覆盖率为窗口持续时间总和除以分析时长，边界处仍在覆盖的窗口标记为截断窗口。
- 日界线场景保留 ECEF 顶点并生成连续展开经度；极区同样直接使用 ECEF 顶点渲染，避免经纬平面在极点退化。
- 沿轨/横轨尺寸及面积使用波束中心处的局部 LVLH 投影计算；面积明确标记为局部投影面积，并非第二阶段的精确椭球几何并集面积。
- 目标命中同时要求目标在卫星地平线以上且位于当前闭合覆盖多边形内。目标统计默认以 1 仿真秒固定步长累积，首次进入/最近离开取对应采样时刻。
- 累计扫描带保存的是固定仿真时刻的覆盖多边形序列，不把渲染帧当作采样点，也暂不计算这些多边形的精确几何并集面积。

## 代码结构

```text
src/
├─ components/  顶部场景与数据工具栏

├─ hooks/       仿真时钟、固定时间任务采样与派生状态
├─ io/          场景协议、目标导入、CSV/GeoJSON 导出和浏览器文件操作
├─ panels/      轨道、姿态天线、目标、实时状态和时间控制
├─ simulation/  任意仿真时刻的统一场景几何与目标观测
├─ stores/      Zustand 场景、时钟、目标统计和历史覆盖状态
├─ viewer/      Cesium 场景、目标、覆盖区与地球拾取
└─ workers/     最多 10000 点的固定时间后台仿真采样
packages/orbital-core/src/
├─ coordinates/ ECI/ECEF、WGS84 经纬高转换
├─ attitude/    LVLH、本体姿态和天线安装矩阵
├─ antenna/     波束边界采样与固定/正弦/线性扫描规律
├─ intersection/射线与 WGS84 椭球求交
├─ coverage/    瞬时覆盖区闭合判定与几何指标
├─ targets/     地面目标观测与进入/离开/累计照射统计
├─ propagators/ 统一传播器接口与圆轨道传播器
├─ time/        可独立测试的仿真时钟
└─ math/        纯向量函数
```

Cesium 渲染组件只消费数学模块的结果，不包含轨道传播或坐标转换公式。

## 当前限制与下一步

当前支持多颗卫星、WGS84、二体/J2 圆或椭圆轨道、TLE/SGP4/SDP4、固定或外部 RPY 姿态时间序列、点/圆/矩形/多边形目标和用户导入的规则网格 DEM；J2 模型不包含短周期项、阻力与高阶重力场。底图采用离线低层级 Natural Earth II 贴图和 1:110m 国界，不包含在线高分辨率地图瓦片。本地 `.gltf` 若引用外部分离纹理或缓冲文件，应改用可访问 URL 或打包为自包含 GLB。二维方向图当前提取包含全局峰值的单一星形主瓣，不合并断开的旁瓣。

当前参考成像面向固定 ECEF 单点目标，采用最近邻 RCMC 与慢时间相干积累；尚未实现高阶插值、完整 RDA/CSA、自动聚焦、分布式散射场景或工程级运动补偿。当前回波是归一化模型，尚未加入天线增益、雷达方程绝对功率标定、传播损耗或杂波；浏览器单次单/多通道回波均限制为 5000000 个复采样点。DBF 使用窄带等效相位中心模型，尚未加入宽带通道误差、互耦与标定。当前阵列馈源是几何级模型，尚未根据反射面焦距、阵列复权或互耦自动合成电磁方向图；相对功率仅作为工程元数据。当前 DEM 是局部规则经纬网，不含瓦片流式加载；目标高程不自动贴附 DEM，入射角仍使用椭球法线，离散视线采样可能漏过窄于采样间隔的尖峰。任务规划当前是确定性的优先级贪心算法，不保证全局最优，也尚未加入姿态机动转换时间、能量、存储和下传约束；完全落在两个粗采样时刻之间的短窗口可能漏检。伴飞星目前使用轻量点模型，不复制主星的机身/太阳翼实体；实时目标着色、累计覆盖历史和相机跟随仍以主星为主。TLE 的 TEME→ECEF 当前采用 GMST 近似链，尚未加入完整 IERS 极移和 UT1 修正。Tauri 本机验证仍需先安装 Rust 工具链；Electron 路径已确认可直接消费当前静态构建产物。
